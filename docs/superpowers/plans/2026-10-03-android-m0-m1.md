### 工具链风险与备选(Task 1 内验证)

haze 2.0.1 的 metadata 由 Kotlin 2.4.20 产出,AGP 9.4.1 内置 Kotlin 2.2.10 读取时理论上报 metadata 版本不兼容。Task 1 按序尝试:

- **方案 A(首选)**:内置 Kotlin 直接编译。若 `assembleDebug` 通过(2.2.10 编译器可能容读 2.4 metadata,实证为准)→ 采用,保持最简。
- **方案 B(备选)**:根目录 `gradle.properties` 加 `android.builtInKotlin=false`,classpath 显式加 `org.jetbrains.kotlin:kotlin-gradle-plugin:2.4.20` 经典 `kotlin-android` 插件 + `org.jetbrains.kotlin:compose-compiler-gradle-plugin:2.4.20`。该 opt-out 在 AGP 9.x 有效(AGP 10 移除)。
- **方案 C(兜底)**:haze 降到与 2.2.10 metadata 兼容的 1.x 版本(玻璃效果 API 不同:`haze`/`hazeChild`),记入偏差。
- 若 Hilt+KSP 与内置 Kotlin 冲突不可解:**手动 DI 兜底**(手写 `AppGraph` 容器,删 Hilt/KSP 依赖;架构文档允许「可换」)。

## 服务端契约(实现 mobile_api.py 的依据,全部已核实)

### 认证
- `POST /api/mobile/auth/login`,JSON `{"username","password"}` → `200 {"token","expires_at"}`(ISO8601)。
- token = `create_session()` 产出的 session id(即复用 sessions 表,`session_ttl_hours=24*14`);后续请求 `Authorization: Bearer <token>`。
- `app/main.py` 的 auth_wall 中间件把 `/api/mobile` 加入早退放行列表(现有:`/static /assets /media /t/ /admin/api/ /api/ext/`),**路由内部自鉴权**(依赖 `get_current_user` 读 Bearer)。
- 错误统一体:所有 4xx/5xx 返回 `{"error":{"code":"...","message":"..."}}`;定义 `ApiError(code, message, status)` 异常 + handler。code 集合:`invalid_credentials`(401)、`unauthorized`(401)、`not_found`(404)、`validation`(422/400)、`server`(500)。

### 端点(均挂 `APIRouter(prefix="/api/mobile")`)
- `GET /discover` → `{featured:[Collection], latest:[Collection], models:[Model], tags:[Tag], stats}`。`Collection` = `_collection_payload` + `coverThumb` 字段;`Model` = `_model_payload`(头像兜底逻辑照抄 web.py:无 avatar 用第一张合集封面);`Tag = {name, collections, models}`;`stats = {collections, models}`。featured/latest 各取前 4/6(同 Web 发现页)。
- `GET /collections?tag=&page=&pageSize=` → `{items:[Collection], total, page, pageSize}`。默认 pageSize 20、tag 可空。
- `GET /collections/{slug}` → Collection + `photos:[{idx, file, w, h}]`(idx 从 0;w/h 可空,来自 photos 表 width/height)+ `model:{slug,name}` + `tags:[str]`。
- `GET /favorites` → `{"collection":[slug...], "photo":[key...]}`(M1 只需 collection 段;photo/model 段照 ext 语义保留)。key 约定沿用 `type:key`。
- `POST /favorites`,JSON `{"type":"collection"|"photo"|"model","key":str,"added":bool}` → `200 {"ok":true}`。落 `favorites` 表(复用 web 侧服务逻辑,勿重复实现)。
- 收藏/发现等读接口**允许匿名**(未带 token 时 favorites 返回空集,discover 照常),登录与否只影响收藏能力 —— 与 Web 端「登录后才能收藏」一致。`GET /auth/me` → `{"username"}` 或 401。

### DTO 与 URL 拼装(客户端)
- 客户端 DTO 只存 `rel` 路径,URL 由 Repo 拼:`$base/media/$rel`(原图)、`$base/t/${w}x${h}/$rel.webp`(缩略图,w 必填;等比时 h 省略为 `/t/${w}/`)。参考 `app/services/media.py`。
- `coverThumb`:列表卡片用 `/t/600x/...webp`;详情 head hero 用 `/t/900x/`;灯箱用原图。

### 工具链结论(Task 1,方案 B 生效)

- **方案 A(内置 Kotlin)失败,已证实**:AGP 9.4.1 内置 Kotlin 2.2.10 的 metadata 读取上限为 2.3.0,
  而 Compose BOM 2026.09.00 传递依赖拉入 kotlin-stdlib 2.4.20(metadata 2.4.0),haze 2.0.1 同样;
  连 `kotlin.Unit` 都无法加载,无绕行空间。
- **采用方案 B**:`gradle.properties` 设 `android.builtInKotlin=false` + `android.newDsl=false`
  (官方要求 opt-out 时一并关闭新 DSL,否则 kotlin-android 插件不可用);
  根 `build.gradle.kts` 用 `buildscript` classpath 显式钉 KGP/compose-compiler/serialization 2.4.20
  (AGP 的插件 marker 把内嵌 KGP 带上 classpath 且版本不可见,`plugins{}` marker 会报版本冲突,
  必须走 conflict resolution);模块内按 id 无版本号应用 kotlin 系插件。
- **haze 2.x 无 `haze-materials`**(1.x 产物,2.x 改为 haze-blur 系列);本项目按主题 token
  自定义玻璃色,不需要 materials,依赖已移除。
- `platforms;android-37.0` + `build-tools;36.0.0` 已装;`platforms;android-37` 这个包名不存在
  (37 系为 37.0/37.1/37.2)。
