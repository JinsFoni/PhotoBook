## 服务端新增(薄层,复用现有 ORM/服务,均挂 `/api/mobile`)

| 端点 | 说明 |
|---|---|
| `GET /models` | `_model_payload` 列表(status=published,featured 优先同 discover);支持 `?featured=1` 供 S1 复用 |
| `GET /models/{slug}` | 模特详情 payload + `collections:[_collection_card](该模特)` |
| `GET /search?q=` | 复用 search_api.py 的匹配逻辑(name+stage+tags+agency / title+model+tags);命中结构:mírate `_model_card`(slug/name/thumb-rel/count/tags)+ `_collection_card`;缩略图一律返回 rel(`t/160/...webp` 前缀形式),客户端自拼 origin |
| `GET /favorites` 扩展 | 已存在;S7 需要 model 段 — 已返回三段,**无服务端改动** |
| `POST /favorites` 扩展 | 已支持 `type=model` — **无服务端改动** |

- 头像/模特图 rel 约定:`avatar`/`hero` 是 `/media/` rel(原图);模特卡缩略 `t/600x/` 前缀 rel(与 coverThumb 同形式)
- pytest:`tests/test_mobile_api.py` 补 models/models-detail/search 形状与边界(空 q、无命中、匿名)

## 客户端新增

### DTO / API(Task M2-1)
- `MobileApi`:`models()`、`model(slug)`、`search(q)`
- `Dtos.kt`:`ModelDetailDto`(payload + `collections: List<CollectionCardDto>`)、`SearchResultDto`(q/models/collections/tags)

### 数据层(Task M2-2)
- `ModelsRepository`:`list()`、`detail(slug)`(DTO→UI 模型;avatar rel → `MediaUrls.thumb(base, rel, 600)`、hero 同;合集卡复用 `CollectionCardDto` 映射)
- `SearchRepository`:`search(q)` → 三段 UI 模型
- `FavoritesRepository`:`toggle` 已支持三段,**新增** `state: StateFlow<Favorites?>`(内存流,便于 S7 页与详情页/灯箱同一事实源);`refresh` 幂等
- DI:无需新 module(构造注入即可)

### UI(Task M2-3 ~ M2-6,严格按 design.md)
- **S5 模特列表**(shell 第 3 页):appbar「模特」Serif 17sp;2 列 ModelCard(2:3 头像 + Serif 15sp 名 + micro「N 个写真」);骨架/空态/错误重试同 S2;点卡 → S6 全屏路由
- **S6 模特详情**(全屏,无底栏):顶部 2:3 hero(statusBar 沉浸 + 底部渐隐纱 + 返回钮白字)→ 刊头(名 Serif 29sp / stage / bio 15sp/1.55 / meta 行:agency · height · measurements 有则显)→ 「写真 N」SectionHeader → 2 列 CollectionCard;点卡 → S3
- **S7 收藏页**(shell 第 4 页):三段 Tab(模特/写真/照片,下划线式 TabRow,self-made:文本 + 2dp accent 底条)→ 模特段 2 列 ModelCard / 写真段 2 列 CollectionCard / 照片段 3 列方图(photo key = `slug:idx`,点 → S4 灯箱);未登录或空态 EmptyState;下拉不刷新(进入时 refresh + 乐观更新已同步)
- **S10 搜索**(S2 appbar 放大镜 → 全屏搜索路由):顶栏内嵌输入框(hairline 下划线,自动焦点)→ 空态热门标签(TagChip 流,点 → 回 S2 带 tag)→ 有 q 三段结果(模特行:40dp 圆头像+名+count;写真 2 列卡;标签 chip 行)→ 点写真情 → S3
- 导航新路由:`model/{slug}`、`search`;shell 占位屏替换
- 收藏心形接线:S3 appbar 心形已有(collection);S7 进入 `vm.refresh()`;灯箱 photo 心形已接;模特收藏在 S6/S7 段落补 FavoriteButton(24dp 描边→accent 实心 spring)

### 主题纪律(同 M1)
- S5 随 shell 当前主题;S6 强制 dark(媒体头部白字,离开恢复 — 复用 S2 的 ThemeState 模式);S7 随 shell;S10 随 shell(从 S2 dark 进入也强制 dark)
- 玻璃底栏 hazeSource 链不变;页面底色画在 pager 内容内部(M1 教训)

### 测试(Task M2-7)
- `ModelsRepositoryTest`:models 列表映射(avatar rel→URL)、detail collections 映射
- `SearchRepositoryTest`:空 q 不发请求(或发——按服务端行为定)、结果三段映射
- `ModelsViewModelTest`:加载/错误/重试
- `SearchViewModelTest`:防抖(debounce 300ms)、空 q 清结果、提交搜索
- `FavoritesViewModelTest`:三段 Tab 内容、toggle 乐观回滚同步
- 沿用 MockWebServer + StandardTestDispatcher + waitUntil 轮询套路;JSON 必须含全部非空 DTO 字段(page/pageSize 教训)
