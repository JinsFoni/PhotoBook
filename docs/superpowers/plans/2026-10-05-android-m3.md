# Android M3 体验补全(S9 设置 + 多服务器 + 主题/语言持久化)

> 依据:android-architecture.md §5/§9(M3)、design.md S9 行。
> 骨架屏/空态(M1/M2 已覆盖全屏)、DownloadManager(S4 已实现)不重复。

## Task M3-1 ServerProfile 多档案存储

- `data/prefs/ServerProfile.kt`:`@Serializable data class ServerProfile(id, baseUrl, label, username)`;token 随档案存
- `SessionStoreApi` 扩展:`profiles: Flow<List<ServerProfile>>`、`activeBaseUrl: Flow<String>`(语义不变,指向活动档案)、
  `addProfile/removeProfile/setActive/saveTheme/saveLocale`
- DataStore 存 JSON(kotlinx.serialization → stringPreferencesKey);旧 baseUrlKey 迁移为首个档案
- `baseUrl` Flow 保持原名与语义,所有 Repo 零改动

## Task M3-2 多服务器网络切换(HostSelectionInterceptor)

- OkHttp 拦截器:每次请求把 `request.url` 的 scheme/host/port 替换为当前活动档案的(路径/查询不动)
- 单 Retrofit/OkHttp/Coil 全复用;Coil 图片 URL 由 Repo 用 `baseUrl` 拼出,天然跟随活动档案
- 401 处理不变;测试:切换档案后请求落点 host 变化

## Task M3-3 主题持久化 + 循环按钮接线

- SessionStore:`theme: Flow<ThemeMode>` + `saveTheme(mode)`
- `ThemeState` 保持内存单例;AppRoot 启动灌入 DataStore 值;ThemeCycleButton/Settings 切换时写回
- ThemeCycleButton 从「装饰占位」变为真切换(EXPLORE/FAVORITES 页)

## Task M3-4 S9 设置页

- `ui/screens/settings/SettingsScreen.kt` + ViewModel + 路由 `settings`
- 区块(自上而下):
  1. **服务器**:档案卡列表(baseUrl + username;活动档案 accent 标记),点=切换;「添加服务器」→ S8(复用登录页,成功后存新档案并激活);滑动/按钮删除(至少保留 1 个)
  2. **主题**:浅色/深色/虚化 三选行(选中 accent)
  3. **语言**:简体中文/繁體中文(A(AppCompatDelegate.setApplicationLocales,即改即用)
  4. **下载位置**:静态说明行 `Pictures/PhotoBook/`(DownloadManager 固定,V1 只读)
- 入口:S8 登录页顶栏设置图标(设计稿 S8 提及设置)+ S1 发现页顶栏右上设置图标(登录后唯一入口;偏差记录)

## Task M3-5 语言 zh-CN / zh-TW

- appcompat 1.7(仅为 per-app locale;Material3 不受影响)
- 字符串抽离:全 UI 硬编码文案 → `res/values/strings.xml`(简体为默认)
- `res/values-zh-rTW/strings.xml` 繁体对照
- LoginScreen/MainShell/GlassTabBar/各屏文案逐一替换;异常词(如服务器返回的 title)不翻

## Task M3-6 测试 + 走查 + 文档

- `./gradlew :app:assembleDebug :app:testDebugUnitTest` 全绿;pytest 不涉服务端改动(回归跑一次)
- 真机走查:S9 全区块、S8→添加第二服务器→切换、主题循环按钮三态、语言切换即改即用
